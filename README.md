# A thief rush

**A thief rush** は、障害物をよけながらお金を拾ってスコアを稼ぐ、シンプルなアクションゲームです。拾ったアーマーで一度だけ衝突を回避することも可能です。  
Javaで作成されており、コンパイルしてすぐに遊ぶことができます。

---

## 🎮 ゲーム内容

- プレイヤーは左右に移動しながら、障害物（岩など）を避けて進みます。
- お金を拾うことでスコアが加算されます。
- アーマーを拾うと、1回だけ障害物との衝突に耐えることができます。
- 高速化や出現頻度を調整することで難易度の変更が可能です。

---

## 🕹️ 操作方法

- ゲーム起動後、「Start Game」ボタンをクリックするとゲームが始まります。
- キーボードの **←** および **→** キーで左右に移動。  
  ※ 全3レーンを移動して、障害物を避けましょう。

---

## 🚀 実行方法

以下のコマンドでゲームをコンパイル＆実行します。

```bash
javac Main.java
java Main
```

## ⚙️ カスタマイズ方法

難易度やゲームの進行速度は、ソースコード内の以下の変数を変更することで調整可能です。

- **ゲームの進行速度**  
  `Model.java` 内の `speed` 変数（デフォルト: `20`）

- **オブジェクトの出現間隔**  
  `Controller.java` 内の変数を変更することで、各オブジェクトの出現頻度を調整できます。  
  数値が小さいほど頻度が高くなります。
  - `rockSpawnInterval`（岩の出現頻度、デフォルト: `30`）
  - `itemSpawnInterval`（お金の出現頻度、デフォルト: `120`）
  - `armorSpawnInterval`（アーマーの出現頻度、デフォルト: `500`）
